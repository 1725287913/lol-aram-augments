# 海斗指南 · 海克斯大乱斗

纯静态的英雄联盟「海克斯大乱斗」攻略站。零框架、零广告、零付费。

**在线地址：https://1725287913.github.io/lol-aram-augments/**

打开就选英雄 → 一屏看到这个英雄该怎么玩：出装、海克斯推荐、胜率组合、对局思路。不用一层层点。

## 核心设计

英雄页从上到下**全部平铺**，没有折叠的 Tab：

```
英雄信息（胜率 / 选取率 / 排名 / 样本量 / 召唤师技能 / 技能加点）
  ↓
流派切换（战士流 57.2% · 坦克流 46.3% · 穿甲流 64.0% · 特殊玩法 5 套）
  ↓
推荐出装（出门装 → 六件成装，前 3 件标记为核心）
  ↓
海克斯推荐（棱彩 / 金色 / 银色分组，按本英雄胜率排序）
  ↓
高胜率海克斯组合（同时拿到这两个，胜率显著更高）
  ↓
对局思路 · 小技巧 · 技能说明（折叠在最后）
```

唯一的「切换」是流派——不同流派的出装和海克斯完全不同，必须分开看。

## 功能

| 模块 | 内容 |
|---|---|
| 英雄列表 | 173 个英雄，中文名 / 称号 / 别名 / 全拼 / 拼音首字母 / 打错字都能搜到 |
| 流派 | 405 套，标注各自胜率与选取率，切换后出装与海克斯整页跟着换 |
| 推荐出装 | 出门装 + 六件成装；前三件用绿框标为核心件，点任意装备看价格、胜率、效果 |
| 海克斯推荐 | 按稀有度分三组，每档默认 6 条（够看且不至于太长），可一键展开全部 100+ 条 |
| 海克斯详情 | 点任意海克斯：完整效果 + 全站胜率/选取/样本 + **在这个英雄身上的胜率/选取/样本** |
| 高胜率组合 | 1556 组双海克斯组合，带胜率，直接告诉你哪两张一起拿最猛 |
| 特殊玩法 | 93 个英雄共 139 套人工整理套路：必需海克斯 + 优先海克斯 + 配套六件装备 |
| 对局思路 | 每个英雄的对线、开团、团战要点 |
| 小技巧 | 55 个英雄共 76 条，关联具体海克斯 |
| 收藏 | 星标收藏，侧栏顶部单独一组，存本地不丢 |
| 随机 | 顶栏一键抽英雄（`R`），不知道玩什么时用 |
| 分享 | 复制当前英雄直达链接，`#英雄名` 打开即定位 |
| 三选一训练 | 随机英雄，棱彩→金色→银色三轮各三选一；选前胜率蒙着，选完揭晓最优解，满分 300 评段位 |

手机端做了专门适配：顶栏只留 logo + 搜索 + 英雄入口，随机/三选一收进侧栏抽屉；流派变两行小卡一屏放下；海克斯行隐藏选取率只留胜率。

## 快捷键

| 按键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `R` | 随机一个英雄 |
| `Q` | 三选一训练 |
| `1` `2` `3` | 训练中选卡 |
| `空格` | 训练中下一轮 |
| `Esc` | 关弹层 / 关侧栏 |

## 搜索

一个输入框全搞定，不用管输入法：

| 输入 | 结果 |
|---|---|
| `剑魔` / `亚索` | 名字、别名直接匹配 |
| `zdr` / `ys` | 拼音首字母：炸弹人、亚索 |
| `zhadanren` / `zhadan` | 全拼，打一半也行 |
| `剪辑` | 同音错字 → 剑姬 |
| `jainji` | 拼音打错字母，按编辑距离认出来 |

## 本地运行

不能直接双击 `index.html`，浏览器会拦掉 `fetch` 读本地 JSON。起个静态服务器：

```bash
cd haodou-web
python -m http.server 8080
# 或 npx serve .
```

打开 http://localhost:8080

首屏只拉 `index.json` + `augments.json` + `items.json` + `meta.json`，点开英雄才请求那一个英雄的 JSON。
