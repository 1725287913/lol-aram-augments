# 海斗指南 · 海克斯大乱斗攻略

一个纯静态的网页版英雄联盟「海克斯大乱斗」攻略站。零依赖、零广告、离线可用。

**在线地址：https://1725287913.github.io/lol-aram-augments/**

打开选英雄 → 看推荐玩法（锻体 / 出装顺序）→ 看核心海克斯（带专属理由）→ 点开看详细说明和小提示 → 逛玩法库。

## 功能

| 模块 | 内容 |
|---|---|
| 英雄列表 | 173 个英雄，**中文名 / 别名 / 拼音 / 拼音首字母 / 打错字** 都能搜到 |
| 推荐玩法 | 每个英雄 3 套出装路线，含锻体属性、出门装、核心装备顺序、备选装、鞋子 |
| **思路点评** | 每套方案带评级徽章（SSS / SS / S / A / B）+ 文字思路 + 核心海克斯快捷入口 |
| **核心海克斯** | 每个英雄专属的人工推荐（**724 条**），每条附「为什么适合他」的理由 |
| **陷阱海克斯** | 看着好但实测不行的（**131 条**），附踩坑原因，避免白拿 |
| 海克斯推荐 | 按该英雄的真实胜率排序，支持棱彩 / 黄金 / 白银筛选、胜率 / 选取率排序 |
| 海克斯详情 | 一句话说明、完整效果、小提示、推荐装备、慎用装备、**搭配更猛 / 互相冲突**、相关玩法 |
| **玩法库** | **23 套**以一个核心海克斯搭建的整套打法，含出装理由与适配英雄，支持关键词搜索 |
| 强力组合 | 每个英雄 10 套三件套海克斯组合，点图标直接看详情 |
| 技能 | 被动 + QWER 完整描述、加点顺序 |
| 改动 | 版本改动、Bug 修复、本模式专属 buff、**官方改动原文**（137 个英雄，251 条） |
| **随机英雄** | 顶栏一键抽一个英雄（`R`），不知道玩什么时直接看 |
| **收藏** | 卡片右上角星标收藏，侧栏顶部单独一组，存在本地不会丢 |
| **分享** | 一键复制当前英雄的直达链接，`#英雄` 后缀打开即定位 |
| **装备详情** | 点任意装备图标看价格、效果，以及哪些海克斯提到过它、哪些玩法用到它 |

界面是深色单页，左侧英雄墙 + 右侧内容区，全部离线可用。

## 快捷键

| 按键 | 作用 |
|---|---|
| `/` | 聚焦搜索框 |
| `R` | 随机一个英雄 |
| `Esc` | 关闭弹层 |

## 搜索方式

一个输入框全搞定，不用管输入法现在是中文还是英文：

| 你打 | 能搜到什么 |
|---|---|
| `剑魔` / `亚索` | 名字、别名的直接匹配 |
| `zdr` / `jj` / `ys` | 拼音首字母：炸弹人、剑姬、亚索 |
| `zhadanren` / `jianji` | 全拼，打一半也行（`zhadan`） |
| `剪辑` | 同音错字 → 剑姬（查询会先转成拼音再比对） |
| `jainji` / `zdran` | 拼音打错字母，按编辑距离认出来 |
| `炸弹壬` | 中文打错一个字（三个字以上才放宽） |
| `劍姬` | 繁体也能认 |

回车直接打开排在最前面的那个。拼音数据分两层：`data/index.json` 里存了每个英雄名和全部别名的全拼 + 首字母；`data/pinyin.txt`（63KB）是汉字→拼音表，只在跑中文容错时才用，空闲时后台预加载，不拖首屏。

## 本地运行

不能直接双击 `index.html`——浏览器会拦掉 `fetch` 读取本地 JSON。起个静态服务器即可：

```bash
# 方式一：Python（装 Python 就有）
cd haodou-web
python -m http.server 8080

# 方式二：Node
npx serve .
```

然后打开 http://localhost:8080

## 部署到 GitHub Pages

1. 把 `haodou-web` 目录里的**全部内容**作为仓库根目录推上去
2. 仓库 Settings → Pages → Source 选 `GitHub Actions`
3. 已附带 `.github/workflows/pages.yml`，推上去会自动部署
4. 一分钟后访问 `https://<用户名>.github.io/<仓库名>/`

也可以选 `Deploy from a branch` → 分支选 `main`、目录选 `/ (root)`。

```

├── assets/
│   ├── css/main.css        全部样式
│   ├── js/app.js           全部逻辑（无框架）
│   └── img/
│       ├── heroes/         英雄头像 ×173
│       ├── augments/       海克斯图标 ×223
│       ├── items/          装备图标 ×195
│       ├── skills/         技能图标 ×865
│       └── spells/         召唤师技能
├── data/
│   ├── index.json          英雄索引（首屏加载，57KB）
│   ├── augments.json       海克斯全量 268 个（含联动表、反向英雄/玩法索引）
│   ├── items.json          装备 196 件（含价格和效果）
│   ├── plays.json          玩法库 23 套（含每个装备与海克斯的推荐理由）
│   ├── pinyin.txt          汉字→无声调拼音表（403 个音节 / 20772 字，搜索容错用，懒加载）
│   ├── meta.json           版本信息
│   └── heroes/<slug>.json  单英雄详情 ×173（点开才加载）
└── .github/workflows/      自动部署到 Pages
```

首屏只请求 `index.json` + `augments.json` + `items.json`（约 500KB），点开英雄才拉那一个英雄的 JSON，玩法库点开时才请求 `plays.json`。

## 数据情况

- 版本：游戏 16.21.1 / 数据 26.21，胜率数据更新于 2026-10-24
- 英雄 173 / 海克斯 268 / 装备 196 / 胜率记录 22,310 条
- 核心海克斯推荐 724 条（158 个英雄）/ 陷阱海克斯 131 条（83 个英雄）
- 玩法库 23 套 / 官方改动原文 251 条（137 个英雄）
- 每个英雄都有：3 套玩法、10 套海克斯组合、完整技能与改动

已知缺口（界面已做占位，不会报错）：

- **海克斯人工小提示**：268 个里 30 个有，其余靠「搭配更猛 / 互相冲突」表和胜率规则给出判断
- **15 个英雄没有核心海克斯标注**（原文未收录）、90 个英雄没有陷阱标注
- **技能图标 2 个**：奥罗拉、纳菲里的被动图标官方源 404，前端显示字母占位
- **海克斯图标 1 个**：原站未收录的少数新符文（如霸符兄弟）无图标

## 数据来源

- 英雄、装备、技能、版本改动：拳头官方 Data Dragon / CommunityDragon
- 海克斯效果与文本：CommunityDragon + 攻略站公开页面
- 胜率与选取率：攻略站公开的静态数据（`/data/hero_augment_rates.json`）
- 图标：全部已下载到 `assets/img/`，不再依赖任何外部域名
